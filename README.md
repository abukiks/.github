### 🌐 About Abukiks

**Abukiks** is a modern, multi-service SaaS ecosystem built around the principles of **reliability, automation, and purpose**.  
It serves as both a **DevOps learning lab** and a **production-grade platform**, demonstrating how scalable systems are built and maintained in the real world.

Each project follows the **12-Factor App methodology**, practicing what modern cloud engineering preaches — from infrastructure as code to continuous delivery and observability.

> 🧭 *We build systems that stay up — and stories that stay meaningful.*

| Service | Description | Status |

### ⚙️ Core Stack

- ☁️ **Cloud & Infrastructure:** AWS EC2, Terraform, Ansible, Kubernetes (EKS/K3s)  
- 🧰 **DevOps & Automation:** ArgoCD, GitHub Actions, Jenkins, Docker, Helm  
- 📊 **Monitoring & Observability:** Prometheus, Grafana, Loki, Datadog  
- 🔒 **Security & Compliance:** Authentik, cert-manager, ExternalDNS, Kyverno, Trivy  
- 🧠 **Languages & Scripting:** Python • Go • Bash • YAML  

---

### 🧩 Sentinel — The DevOps Core

> **`sentinel.abukiks.com`** is the backbone of the entire Abukiks platform.

**Sentinel handles:**
- 🚀 Continuous GitOps Deployments (ArgoCD)  
- 🧱 Infrastructure as Code (Terraform + Ansible)  
- 🔍 Policy Enforcement & Security (Kyverno + Trivy)  
- 📊 Monitoring & Metrics (Prometheus + Grafana)  
- ⚡ Cluster Autoscaling & Node Management (Karpenter)  
- 💰 Cost & Resource Optimization for AWS workloads  

Sentinel is more than a CI/CD system — it’s the **orchestrator of reliability**.  
Every other Abukiks service lives under its supervision, from Auth to Failsim.
